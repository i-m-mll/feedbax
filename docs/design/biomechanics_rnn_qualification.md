# Biomechanics RNN qualification

The two-link fixture is inspired by Li and Todorov's 2004 arm control task. It uses Feedbax's two-link mass, pivot inertia and damping conventions and body-fixed paths. The authored MuJoCo arm converts pivot inertia to center-of-mass inertia and compiles the two damping modes into native passive tendons. The benchmark compares the full mass matrix, Coriolis force, passive damping, path geometry, stage acceleration and 0.6 s trajectory against the independent analytical plant before timing. Both plants use the same law bank, continuous solver stages and physical parameters.

The JSON protocol defines the local macOS CPU workload, perturbations, seed streams, acceptance bounds and execution budgets. Use the production recurrent controller, feedback graph, trial preparation, task loss and supervised optimizer update. The 10 ms feedback clock applies at every physics resolution. Running position and command costs use a 10 ms rectangle quadrature across observations. Each held-out bank has 32 trials, covering eight directions at each of two radii with quiet and disturbed trials. A held-out pass requires 90th-percentile terminal position error within 15 mm, 90th-percentile terminal speed within 0.12 m/s and RMS excitation at most 0.55. These thresholds require accuracy well below the smallest 60 mm reach, approximately stationary endpoints at the feedback clock, and bounded average effort. Require two of three seeds to reach the target for the workload to pass.

Start Euler diagnostics at 1 ms and compare the same controller and replay keys at 0.5 ms and 0.25 ms. Compare task loss, endpoint and full-loss derivatives at initialization and at a passing trained checkpoint. A 2 mm change is roughly one eighth of the allowed terminal error, and the loss tolerance is below a tenth of the squared terminal position target. For each direction, require two adjacent finite-difference steps within the larger of the relative and absolute error limits. An unresolved float32 cancellation or branch crossing calls for float64 diagnosis. Use the coarsest step supported by the refinement data before judging comparable timing and learning. Time the analytical reference and MJX with rigid Hill at the training batch. Use activation-to-force and batch one only as diagnostics.

The production rows run sequentially under local resource admission. Collect synchronized compilation and forward, VJP record, pullback and full-update times in fresh processes, with persistent compilation cache disabled. Record high-water process RSS separately. The training loop measures the first held-out check meeting all criteria and reports an unobserved time to target if the update, elapsed or memory cap is reached. A single focused diagnosis may repair a missed gate, with exact changed inputs recorded before rerunning affected rows. A loss or update count alone cannot establish learning.

Run from the repository root with the locked Python 3.12 dev and MJX environment. Use `python -m scripts.qualify_biomechanics` with the requested phase, the protocol via `--lock`, and a row-specific JSON path via `--out`. Record source and model identity with each row. A trained net can be saved for replay with `--save-net` and restored in gradient diagnostics with `--load-net`.

For the exterior-wrap row, pass `--wrap-shoulder` with MJX. This replaces only the shoulder antagonist paths with two mirrored routes around a 0.062 m cylinder. Origin and insertion radii are 0.07 and 0.12 m, with 2.10 rad initial separation and 0.095 m side-site radii at the angular midpoints. Slack lengths put the fibers at the same optimal length as the fixed-guide row at the start pose. The qualified active-route interval is ±0.45 rad about the initial shoulder angle. The runner records the shoulder angle envelope on its gradient batch and, after training, on the held-out trials using the final trained network. The envelope includes the initial pose and the sampled feedback ticks at 10 ms intervals.
