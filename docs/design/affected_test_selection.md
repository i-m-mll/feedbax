# Affected test selection

Run `uv run --no-sync python scripts/affected_gate.py --base <commit>` for the automatic affected gate. It runs dependency-related Python and Studio tests, plus browser and build checks for Studio changes. Run `uv run --no-sync python scripts/affected_gate.py --reference` for the complete reference gate. The existing CI continues to run the reference checks on protected delivery. `uv run --no-sync python -m scripts.affected_tests --base <commit>` prints the selection and any widening reason without running tests.

Pants supplies only the Python reverse-dependency graph. The selector generates temporary first-party targets from the checkout and pins Pants engine 2.33.0. If `pants` is absent from `PATH`, it downloads the scie-pants v0.13.2 launcher into the user cache and verifies a platform-specific SHA-256. [Pants installation](https://www.pantsbuild.org/stable/docs/getting-started/installing-pants) documents the launcher and checksum scheme. uv and Bun remain the project dependency, lock and execution authorities. Studio related tests come from the installed Vitest graph; browser and build checks remain separate.

The initially proved narrow scope covers PPO implementation and direct Python test edits, and Studio TypeScript source and test edits. Affected Python execution includes all selected tests in a related file, whether marked routine, extended or slow, within the core capability profile. Shared graph/registry/contracts, generated contracts, deleted or renamed sources, unrecognized paths, external plugin changes and unavailable inference widen to the complete gate with an explicit reason. Optional MJX/PPO capability gates are separate. The full reference includes clean-wheel conformance, generated-contract drift, Python core, Studio unit/browser checks and build.

Use `--replay <commit> --source-only` on the selector to test historical production paths against the current graph. The source-only PPO and Studio persistence replays selected the existing witnesses that failed under seeded regressions. Generated component-source projection, graph-spec and fixture edges are integrated with the registry lane before narrowing component and plugin changes.
